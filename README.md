# Java Internship Projects — Yuva Internship

This repository contains Java projects organized by internship phase.

## Project Structure

### Phase 1: Fundamentals and Setup
- Java development environment setup
- Basic Java program
- Introduction to Java execution

### Phase 2: Core Java Concepts and Skills
- Object-oriented programming concepts
- Student management using Java collections
- CRUD operations using an in-memory data structure

### Phase 3: Practical Implementation
- Student Management System
- Java JDBC integration with MySQL
- Database operations using prepared statements
- Maven-based dependency management

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Collections Framework
- JDBC
- MySQL
- Maven
- Git and GitHub

## Prerequisites

- JDK 17 or compatible newer JDK
- Maven
- MySQL Server (required for Phase 3)

## Getting Started

Open the individual phase folder and follow its README for setup and execution instructions.

For Phase 3, configure the database and set the `DB_USER` and `DB_PASSWORD` environment variables before running the application.

## Repository Purpose

This repository organizes my work and learning across the Yuva Internship phases. See each phase's README for implementation details.
